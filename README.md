# AI Product Portfolio · Chris Haoyu Geng

[打开作品集 / View portfolio](https://chrisghubhub.github.io/ai-product-portfolio/)

AI 不止是技术概念，更是问题的一种回答。

围绕真实需求、技术可能性与商业判断展开的五个项目与原型：

1. **不买账实验室** — 从消费表达识别购买阻力，提出研究假设与增长实验。
2. **BrowserKitten** — 电商竞品追踪与浏览器 Agent；首次商业化尝试。
3. **Live2D 桌宠 / Companion Atlas** — 长期记忆、桌面陪伴与十位角色的关系设计。
4. **林知夏** — 桌宠衍生的记忆与回应机制体验。
5. **Chris Trade** — 以对话驱动工作过程的 AI-native 探索。

[Companion Atlas 产品与角色档案](projects/companion-atlas/)

## 体验说明

- 中文 / English 可在页面右上角切换。
- 不买账与 Chris Trade 的合成数据、模拟分析和订单均在对应项目中标明。
- 林知夏使用规则与剧情回复，聊天与记忆仅存于当前浏览器，不调用真实模型。
- BrowserKitten 需要安装 Chrome 扩展并自行配置模型服务。

## 网站结构

纯静态 HTML / CSS / JavaScript。GitHub Pages 从 main 分支根目录发布；无需后端、账号或构建步骤。角色档案中的人名与故事是产品设计设定。
